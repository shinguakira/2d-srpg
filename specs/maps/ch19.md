# Chapter 19 Map: "The Offer"

## Overview
- Grid size: 20×22
- Tileset: Circuit, wall, data_node, void, archive_tile, plain (smooth data floor), throne (terminal)
- Terrain focus: System inner sanctum. Symmetrical corridors with branching side rooms. Memory archive tiles that trigger flashbacks. Linear push toward a terminal.

## Layout
The System's inner sanctum — clean, symmetrical architecture. The south (rows 18-21) is the entry hall: a wide 6-tile corridor of smooth data floor. The main corridor runs north from (17, 10) to (3, 10), 4 tiles wide. Three side rooms branch off: west room (rows 14-16, cols 1-5) holds ghost boss spawn points, east room (rows 14-16, cols 16-20) contains the hidden Memory Shard tile, and a central archive chamber (rows 8-11, cols 6-14) where ghost bosses appear. Walls create chokepoints at (12, 8-11) and (7, 8-11) — 4-tile-wide doorways. The Memory Guardian sits at (4, 10) blocking the terminal. The terminal throne is at (1, 10). A hidden tile at (15, 19) contains Kael's Memory Shard — no visual indicator. Void strips along the east and west edges (cols 0, 21) prevent wall-hugging.

## Tactical Notes
- **Memory Guardian strategy**: Low DEF (10) but high RES (22). Physical damage is the key — Bram, Rook, Voss, and Ghael excel. The Guardian's ghost summons create action economy pressure: deal with echoes quickly or they overwhelm flanks.
- **Ghost boss management**: Ghosts have 60% original stats and follow original AI. Ghost Garrek charges (aggressive), Ghost Thane patrols (guard), Ghost Morryn holds position (stationary). Prioritize Morryn — he blocks the corridor to the terminal.
- **Hidden Memory Shard**: The tile at (15, 19) has no visual indicator. Send any unit (preferably Rook, who starts nearby) to step on it. The +2 all stats buff is significant for the boss fight ahead.
- **Burst damage required**: The Guardian regenerates 3 HP/turn and summons reinforcements every 3 turns. Slow attrition fails. Use Orin's Dance to enable two attacks in one turn from a strong physical unit.
- **The Offer**: After defeating the Guardian, Ren seizes the terminal and the System presents the reset offer. The choice (Accept/Refuse) is narratively impactful but mechanically identical — the game continues regardless.
- **Side room exploration**: The west room (rows 14-16, cols 1-5) is where ghost bosses first appear. The east room holds the hidden Memory Shard at (15, 19). Clearing both rooms is optional but rewarding.
- **Chokepoint defense**: The two 4-tile doorways at rows 12 and 7 are natural defensive positions. Park a tank at each while dealing with ghost bosses, then push through once the corridor is clear.
