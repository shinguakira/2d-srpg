# Chapter 17 Map: "Data Recovery"

## Overview
- Grid size: 20×20
- Tileset: Circuit, data_node, wall, void, door, plain (archive floor), fog tiles
- Terrain focus: Dungeon corridors with fog of war throughout. Data nodes to capture. Hidden enemies behind fog. Torch-dependent exploration.

## Layout
A labyrinthine archive dungeon. Fog of war blankets the entire map — vision limited to 3 tiles. The south (rows 16-19) is the entry corridor: a 4-tile-wide hallway with archive floor tiles. Three branching paths split at row 14: west corridor (cols 0-5), central corridor (cols 8-11), and east corridor (cols 14-19). Each branch leads to a data node. Node Alpha sits at (12, 3) down the west branch — lightly guarded. Node Beta at (7, 17) down the east branch — moderate guard. Node Gamma at (3, 10) at the map's deepest point — heavily guarded. Walls form tight corridors (2-3 tiles wide). Doors at (14, 4), (14, 10), and (14, 16) block each branch until opened. The Blackflame boss manifests at (1, 10) after all three nodes are captured. The exit is at (19, 10) — south edge center. Four void pockets at (6, 1), (6, 18), (10, 5), (10, 14) spawn patrol constructs.

## Tactical Notes
- **Fog of war**: Vision is 3 tiles. Fenn has +1 fog vision (thief passive). Elin can scout over walls. Stay tight — separated units can be ambushed by fog-hidden constructs.
- **Three branches, one party**: Splitting into three groups is risky with 12 units. Recommended: clear one branch at a time, or send Elin/Fenn as scouts while the main force pushes center. Node Alpha (west) is easiest — start there.
- **Node capture reveals fog**: Each captured node clears fog in its corridor. This is both tactical (vision) and narrative (data recovery). Capturing nodes in order (Alpha, Beta, Gamma) follows the story beats.
- **Negotiation vs combat**: If party INS is 70+ and the Blackflame is reduced below 50% HP, Shigeru can Talk. The negotiation path skips the archive collapse timer. The combat path requires a 4-turn escape — plan your position before engaging.
- **Escape timer**: After the boss encounter, the archive collapses in 4 turns. Space-filling constructs clog corridors. The exit at (19, 10) is south — don't push too far north before resolving the boss.
- **Door management**: Fenn lockpicks doors instantly. Other units need 2 hits to break them. Budget one turn per door if Fenn is elsewhere.
- **The Blackflame's regen**: 5 HP/turn from archive data streams makes prolonged fights punishing. If going the combat route, burst the Blackflame from 50% to 0 in 2-3 turns using Dance-enabled attackers.
- **Fog ambushers**: Two hidden constructs in void pockets activate when units pass within 2 tiles. Fenn's extended fog vision helps spot them. Elin flying overhead also reveals hidden units within her vision range.
- **Turn 12 lockout**: If data nodes aren't captured by Turn 12, they begin locking permanently. The chapter becomes unwinnable if all three lock. Prioritize node capture over enemy elimination.
- **Torch items**: If available, torches expand fog vision by +3 tiles for 5 turns. Essential for the deeper branches where enemy density increases.
