# FE 聖魔の光石風 2D SRPG

『ファイアーエムブレム 聖魔の光石』(GBA) の戦闘システムと会話パートを再現した
2D シミュレーション RPG。TypeScript + Canvas 2D のみ。ゲームエンジンもフレームワークも
状態管理ライブラリも使っていない。

```bash
npm install
npm run dev      # http://localhost:5173
```

### 開発コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run build` | 型チェック + 本番ビルド |
| `npm run lint` / `lint:fix` | oxlint（`--fix` で自動修正） |
| `npm run format` / `format:check` | oxfmt |
| `npm run knip` | 未使用のファイル・エクスポート・依存の検出 |
| `npm run check` | tsc → oxlint → oxfmt --check → knip をまとめて実行 |

設定は `.oxlintrc.json` / `.oxfmtrc.json` / `knip.json`。
oxfmt は Markdown を対象外にしている（表の桁揃えが全角文字を 1 桁と数えて崩れるため）。

## 操作

| キー | 動作 |
| --- | --- |
| ↑↓←→ / WASD / マウス移動 | カーソル |
| Z / Enter / 左クリック | 決定（ユニット選択 → 移動先 → コマンド → 対象）／会話送り |
| X / Esc / 右クリック | キャンセル（移動前の位置に戻る）／会話の早送り |
| R | カーソルの下のユニットの詳細（左右でページ） |
| E | 自軍フェイズを終了 |
| Shift+R | リスタート |
| 指でのタップ | マスを押すと決定。押したまま滑らせるとカーソルだけ動く |

章の目標は章ごとに違う（制圧 / 全滅 / ボス撃破 / 耐久 / 脱出 / 開通の六種）。
敗北条件はロード（シゲル）の死亡、そして章によっては「守る相手」の死亡。
**スマホでも遊べる** —— 縦持ちなら画面を 90 度回して全面に広げ、盤の左右の柱に
決定・戻る・メニュー・詳細のボタンが出る。

## 仕様書

**計算式・システムの仕様は `specs/systems/` にある。**
コードから書き起こしたもので、こちらが正。

| | |
| --- | --- |
| [combat.md](specs/systems/combat.md) | 戦闘計算（命中・ダメージ・追撃・特効・経験値） |
| [units.md](specs/systems/units.md) | 能力値・クラス・武器レベル・クラスチェンジ |
| [support.md](specs/systems/support.md) | 支援システム（属性表・3マス判定・友好度） |
| [map-and-turns.md](specs/systems/map-and-turns.md) | 地形・移動・ターン進行・敵 AI |
| [presentation.md](specs/systems/presentation.md) | 描画・カメラ・スプライト |

`specs/story/` はアマギ島を舞台にした25章のキャンペーン設計。**二十五章すべてが
組み上がっていて遊べる。** 仕様書に書いてあってコードに無いのは、いまはエンディング
の判定（`takeshiSpared` などのフラグを集計するパス）だけ。

## 実装済みの要素

**戦闘計算** —— GBA 系 FE の式そのまま。**命中判定は 2RN**、武器三すくみ（威力±1 /
命中±15）、特効は武器威力×3、必殺は×3、追撃は攻速差4以上、S ランクで命中・必殺+5、
経験値はクラス補正込みの聖魔式。救出中は技と速さが半分。

**ユニット** —— 能力10種、武器レベル E〜S と熟練度、聖魔式の**2択クラスチェンジ**、
援護（Aid）、支援（属性の組み合わせ／3マス以内／合計5ランクまで）。

**マップ** —— 地形22種と守備・回避・毎ターン回復、玉座の魔防+5、飛行は砦・門・
玉座しか地形効果を受けない。移動タイプ別コスト、ダイクストラの移動範囲、経路矢印。
**カメラ**は盤面が画面より大きくてよく、注目点を追ってスクロールする。

**アーク3から先の地面** —— **灰**（立つと毎ターン最大 HP の一割、守備 −1、回避 −10。
1 で止まる。魔物は免疫）、**聖域**（灰が越えない唯一の床）、**裂け目**（灰の行き着く
先。通れない）、**外海**（水辺と違って誰も入れない硬い境界）。地形は章の途中で
書き換わることがある —— 第15章の灰の際と、第24章の落ちていく崖道。

**戦場の霧** —— `ChapterDef.fog` に視界の半径。見えないマスは幕が下り、その下の敵は
描かれない。砦・門・玉座に立つと二マス遠くまで見える。第12章だけが使う。

**章の目標** —— 制圧 / 全滅 / ボス撃破 / 耐久 / **脱出** / **開通** の六種。どれにも
「守る相手」（倒れたら敗北）を独立に足せる。脱出は誰でも出られてロードが出た時点で
終わり、開通は第24章の岬の岩山 —— 魔道書か杖の者が岩の面に三ターン立って石の筋を
見つけ、そのあと岩の面と両隣に立つ者の力を足していく。穴が通っても勝ちではなく、
**開いた穴の向こう側にロードが立って、はじめて終わる。** 壊すのではなく抜けるのが
目標。**門ではない。掘った結果、洞門になる。**

**コマンド** —— 制圧 / **脱出** / 訪問 / 宝箱 / 扉 / 武器屋 / 闘技場 / 攻撃（**武器を
選んでから対象**）/ 杖（回復・リザーブ・スリープ等）/ 救出・降ろす・引き取る /
輸送隊 / トレード / 会話 / 支援 / 道具 / 待機。騎馬と飛行は行動後に**再移動（カント）**。

**状態異常** —— 睡眠・沈黙・狂戦・毒。杖と毒の牙が撒き、リザーブが解く。

**増援** —— 章の定義に `{turn, at, seed}` を並べると、そのターンの頭に湧く。
`when: {x, y, r}` を足すと**引き金式**になり、自軍がそこへ踏み込むまで待つ。

**章の外** —— タイトル（中断から再開 / はじめから / つづきから / ガイド）、
ワールドマップ（章・行商・影の塔・魔物の群れ）、準備画面（ユニット / アイテム /
支援 / マップ確認 / セーブ / 出撃）、セーブと**中断**。

**画面** —— 常設の HUD は置かない（GBA FE もそう）。地形ウィンドウ、ユニット
ウィンドウ、戦闘予測、フェイズ頭の目標ウィンドウが出入りするだけ。オプションは
10項目（戦闘アニメ3段階・ゲーム速度・文字送り・各ウィンドウ・目標表示・オート
カーソル・オートターンエンド・ウィンドウカラー）。

**敵 AI** —— 攻撃可能な全マス × 全対象を評価（期待ダメージ・撃破可否・反撃リスク・
地形）して最善手を選ぶ。`aggressive` / `guard` / `boss`。狂戦は敵味方を見ない。

**魔物** —— 屍兵・バエル・モーグル・ガーゴイル。光魔法と神聖武器が特効。

## 会話パート

FE 風のテキストボックス（立ち絵 + 名前ウィンドウ + タイプライター表示）。

| 種類 | 発生条件 | どこに書いてあるか |
| --- | --- | --- |
| 前口上 | 章の頭 | `story/chapters/chN.ts` の `opening` |
| 戦闘前会話 | シゲルがそのボスに隣接して「会話」→ ボスの守備 −2 | 同 `bossTalk` |
| 説得 | シゲルが対象に隣接して「会話」→ **仲間になる** | 同 `recruit[id]` |
| ターン事件 | 決まったターンの自軍フェイズの頭 | 章の定義の `events[].script` |
| 幕切れ / 敗北 | 決着時 | 同 `ending` / `defeat`（共通の敗北は `chapters/common.ts`） |
| 支援会話 C/B/A | 隣接した支援ペアで「支援」コマンド | `story/supports.ts` |
| 死亡時のセリフ | ユニットが倒れたとき | `story/script.ts` |

**台本は全部で206本 / 1321行。** 通しで読むなら `/story.html`（下記）。
**登場人物はゲームの言葉を知らない** —— 章もターンも盤も台詞に出さない。規則は
[AGENTS.md](AGENTS.md) にあり、読み物ページが検査する。

## 閲覧ページ

書いたものを、遊ばずに全部見るための三つ。

### `/story.html` —— 通しで読む

**台本を頭から終わりまで読むページ。** dev サーバでだけ出る（vite の入口は
`index.html` だけなので production の束には入らない）。`src/storyPage.ts`。

左に章の目次、右に本文。話者は行頭の桁に色分けで並び、地の文は落として斜体。
検索は節ごと絞り込んで一致箇所に印を付けるので、**言い回しがどの章に散って
いるかがそのまま見える**（「当番」で引くと第23章と終章の六本だけが残る）。

読むついでに粗も出す ——

- **ゲームの言葉**（章・ターン・盤・ユニット…）が台詞や地の文に混ざっている行。
  規則は `AGENTS.md`。`［目標］…` の行と `（このターン、〜）` の挿入は画面の口
  なので対象外
- 顔グラの無い話者（`who` が `PORTRAIT_UNITS` に無い）
- 吹き出しが出せない `**` が本文に混ざっている行
- 一息で読ませるには長い行（64 字以上）

`?q=灰` で検索した状態から開く。「id を出す」を入れると話者 id と台本 id が並ぶ。

### `?dev=story` / `?dev=maps` —— canvas のほう

`src/render/devBrowse.ts`。読むのには向かないが、**本編とまったく同じ演出で
一本再生できる**のはこちら。盤の閲覧も同じ画面群にある。

```
?dev=story           台本一覧 —— ↑↓ で選んで Z で再生。?s=132 でその行から開く
?dev=maps            盤の閲覧 —— 章の盤を一枚に収めて、出撃・敵・ボス・増援・
                     村・宝・味方NPC の位置と、章ごとの内訳を出す。?ch=24 で直接
```

| 画面 | ↑↓ | ←→ | Z | X |
| --- | --- | --- | --- | --- |
| 台本一覧 | 一行ずつ | 十行ずつ | 本編と同じ演出で再生 | 盤の閲覧へ |
| 再生中 | — | — | 送る | 閉じる |
| 盤の閲覧 | 盤を切り替え | 盤を切り替え | 全部の盤を点検 | 台本一覧へ |
| 盤の点検 | — | — | 戻る | 戻る |

盤には本編二十五章のあとに影の塔と魔物の群れが続く。**点検**は置き間違いを名指しする
—— 通れない地形の上のユニットや湧き口、地形が村でない村、玉座でない制圧目標、
盤に出てこないのに「守れ」と言われている者、名簿にいない強制出撃。増援の湧き口は
`Game.freeNear` が近くの床へ逃がしてしまうので、遊んでいる限り気づけない。

## 絵づくり

**盤の上とマップのスプライトは、シゲルとアキラだけが画像。**
`src/assets/sprites/shigeru-sheet.png`（46フレーム / 7クリップ）と
`akira-sheet.png`（38フレーム / 6クリップ、歩行なし）を `render/sprites.ts` が
切り出して描いている。PixelLab に登録したキャラクターから生成しているので、
全フレームが同じ絵になっている。それ以外は PoC から引き継いだコード描画のまま。

**会話の顔グラは別物で、口をきく者は全員持っている。** `src/assets/portraits/`
に40枚。シゲルとアキラ以外は**シゲルの一枚を style image に渡して**一枚ずつ
起こしたので、四十人ぶんが同じ絵描きの手になっている。コード描画の顔が出るのは
登録の無いユニット（名無しの敵・村人）だけ。作りかたと失敗の型は
[assets/portraits/README.md](src/assets/portraits/README.md)。

**新しく描き足すのは禁止**（コードで描く、という意味で）。理由と、絵を増やすときに
何をしてよいかは [AGENTS.md](AGENTS.md) にある。

引き継いだコード描画は GBA 系 FE の実画面を見て次の特徴を取り込んでいる。

- **会話**: 枠なしの立ち絵が画面下端で切れ、クリーム色の吹き出し（茶色の縁＋話者へ伸びるしっぽ）に濃色のテキスト
- **顔グラ**: 髪のシルエットを顔より大きく取り、毛先を尖らせる。目はアーモンド型で虹彩をまぶたで切り、
  太い上まつげとハイライトを入れる
- **UI**: 青灰グラデーションのウィンドウ＋明色の細枠。ラベルは金、数値は白の縁取り文字
- **コマンドメニュー**: 上下に木のバーが付いた巻物風。選択カーソルは指差しの手
- **戦闘画面**: 上隅に金枠の名前プレート、隅に 命中/威力/必殺 の小箱、HP は目盛り式ゲージ
- **マップスプライト**: 2.5 頭身、暗色のアウトライン、受け光、武器を持つ腕
